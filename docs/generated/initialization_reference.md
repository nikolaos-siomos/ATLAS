## Purpose

The initialization file tells ATLAS where the input data and metadata files are located, which QA tests, quicklooks, background plots, and VLDR plots should be produced, and which optional filtering, trimming, export, and radiosonde parsing settings should be applied for one processing run.

This page is generated automatically from the initialization parser schema and the user-facing template flavor text. Edit `src/atlas_actris/templates/init_template_flavor.py` to change descriptions, examples, or version notes. Edit `src/atlas_actris/templates/template_profiles.py` to change which parameters are included or their ordering. Edit `src/atlas_actris/utils/parse_init_file.py` only when the technical schema itself changes.

## How values are interpreted

- Empty values mean that ATLAS will use the schema default or automatic selection when available.
- List values can be separated with commas or semicolons.
- Boolean values must be written as `True` or `False`.
- Relative explicit paths are resolved relative to the folder containing the initialization file.
- Measurement folder aliases in `explicit_folders` are resolved relative to `parent_folder`.

    - **Category:** `optional`
    - **Default:** `empty parameter --&gt; ignored or automatic selection`
    - **Example:** `garmish`
    - **Version history:** New in ATLAS `1.0.0`.

    ```ini
    cloudnet_station_name =
    ```

<a id="rsonde-station-name"></a>
??? info "`rsonde_station_name`"

    Radiosonde station name displayed in plots. If an ECMW file is used, the station name is used for displaying instead and this parameter is ignored.

    - **Type:** `str`
    - **Category:** `optional`
    - **Default:** `empty parameter --&gt; ignored or automatic selection`
    - **Example:** `Thessaloniki`
    - **Version history:** Moved in ATLAS `&lt;=0.5.0`.

    ```ini
    rsonde_station_name =
    ```

<a id="rsonde-station-wmo-id"></a>
??? info "`rsonde_station_wmo_id`"

    WMO identifier of the radiosonde station. If provided, ATALS will attempt downloading Wyoming radiosonde filed to extract the temperature, pressure, and relative humidity.

    - **Type:** `int`
    - **Category:** `optional`
    - **Default:** `empty parameter --&gt; ignored or automatic selection`
    - **Limits / allowed values:** Minimum: 0
    - **Example:** `16622`
    - **Version history:** Moved in the current ATLAS version. Previous name: `rsonde_wmo_number`. Before ATLAS 1.0.0 this parameter was used for display. Since ATLAS 1.0.0 it is used for automatic downloading of Wyoming radiosonde files.

    ```ini
    rsonde_station_wmo_id =
    ```
